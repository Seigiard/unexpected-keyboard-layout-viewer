# Unexpected Keyboard Layout Viewer

Run `npm ci` to install dependencies and Lefthook's pre-commit hook.

Before commit, staged HTML, JavaScript, TypeScript, CSS, Sass, or JSON changes
trigger the existing Parcel production build. Staged whitespace is also checked.
Build output stays under the ignored `dist/` directory.

Use `npm run dev` for development and `npm run build` for a manual build.
Installs without `.git` skip hook setup.
